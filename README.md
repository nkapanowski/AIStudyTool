# AIStudyTool

This AI-powered study tool is designed to personalize learning for each user. Using AI, Firebase, and modern UI tools
like SceneBuilder or React, it helps students create flashcards, quizzes, and custom study methods that evolve based on
their learning patterns and progress.

# Instructions
-Need Java 21 or higher and Maven
-Clone Repo
-Replcae lines 21-22 in AuthService.java with the keys given
-Add firebase_creds.json to your own code in /AI STUDY TOOL
-RUN USING .\mvnw javafx:run

# NOTE 
Do NOT commit AuthService.java changes with real keys
Do NOT commit firebase_creds.json to the repo
Both files are already in .gitignore
